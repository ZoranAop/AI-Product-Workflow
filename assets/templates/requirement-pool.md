# Requirement Card (Small-Tier Requirement)

Use for small requirements where a full PRD is overkill. Combine with the acceptance criteria below.

```
ID: req-XXXX-<short-name>
Title:
Status: candidate
Priority: P0 / P1 / P2 / P3
Owner:
Problem:
Why now:
Target user / scenario:
Expected outcome:
Core metric / baseline:
Out of scope:
Open questions:
```

- [ ] <checkable criterion 2>
