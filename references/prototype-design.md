# Prototype and Interaction Design Constraints

Always supply design constraints before asking the Agent to generate a prototype.

## Provide First

- Existing pages (screenshots or links)
- Design system
- Component library
- Interaction rules
- Platform guidelines
- Reference products
- Existing page screenshots

Without constraints the prototype looks good in isolation but fails to fit the real product.

## Rule

A prototype that cannot be integrated into the existing design system is not accepted as-is; it is treated as a visual direction, not a deliverable. Record which constraints were applied next to the prototype in `90-assets/` or the requirement folder.
